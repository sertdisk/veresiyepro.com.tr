# veresiyepro.com.tr
 İşlem geçmişine değil, yapılacak işlemlere odaklanan windows veresiye programı. İşlem geçmişine değil, yapılacak işlemlere odaklanarak,  hazır listeler ve gelişmiş analiz, inceleme istatistikleri ile veresiye yönetiminize rehberlik eder. Tahsilat başarınızı artırmaya yardımcı olur.
